# PLP-Python-Final-Project

## Django Weather App

A simple Django-based weather application that fetches current weather data using the OpenWeatherMap API.

### Features

- Search for current weather by city name
- Fetches data like temperature, humidity, pressure, weather description, and icon
- Clean, responsive UI (using Tailwind)
- Graceful error handling API issues

### Tech Stack

- Python 3.8+
- Django 4.x
- OpenWeatherMap API
- HTML/CSS, Tailwind
